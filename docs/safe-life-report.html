澳门街坊总会广东办事处 · 莲花社区服务点

一、本次新增内容

在服务首页新增「安心生活」专区，面向社区长者，包含三大功能模块：防诈骗、脑力训练、健康运动，并配套工作人员查看页。设计上遵循长者友好原则：正文 ≥18px、标题 ≥24px、按钮 ≥48px、高对比、一页一个主要操作、图标旁必带文字、手机竖屏优先。基础版为手动录入，不接外部设备、不接 AI，不做医疗诊断，不宣传「自动判断诈骗」。

二、长者端页面（4 个新页面）

页面功能
safe-life.html
安心生活首页		 输入「手机号后四位 + 姓名」识别（精确匹配已有档案，不自动建档）→ 三大功能卡：🛡防诈骗 / 🧠脑力训练 / 🏃健康运动
antifraud.html
防诈骗		 ① 今日诈骗提醒（含「播放语音」朗读）
② 常见诈骗案例 6 类（冒充子女亲友 / 冒充公安检察院 / 快递退款 / 保健品推销 / 网络投资理财 / 养老服务骗局），每类含「骗子怎么说 / 哪里可疑 / 应该怎么处理」
③ 防诈骗小测试（一次一道、大按钮、即时对错反馈 + 解析）
④ 求助入口 3 个（联系家属 / 联系工作人员 / 拨打 96110 或 110）
braintrain.html
脑力训练		 三种训练：记忆力 / 注意力 / 生活能力，各 5 题、一页一题、大按钮；难度默认「轻松练习」，其余标「后续开放」；完成显示正确题数 + 用时 + 鼓励语并保存；页底注明「训练结果仅用于日常脑力活动和状态观察，不作为医疗诊断依据」
exercise.html
健康运动		 顶部 4 项数据（今日运动分钟 / 今日步数 / 本周运动次数 / 连续活动天数）；「记录一次运动」→ 表单（8 类运动：散步 / 八段锦 / 太极 / 广场舞 / 拉伸运动 / 健身操 / 游泳 / 其他 + 日期 + 时长 + 步数/距离选填 + 感受 4 档 😊很舒服 / 🙂还不错 / 😐有点累 / 😣不舒服）；选「不舒服」额外显示休息就医提醒；下方展示最近记录

三、工作人员查看（后台新增）

后台 admin.html 新增「安心生活」Tab，登录后可查看每位长者的：

  • 防诈骗阅读情况（读了哪些板块）
  • 脑力训练（日期 / 次数 / 正确率）
  • 运动记录（日期 / 类型 / 时长 / 感受）
  • 求助记录 + 跟进状态（待跟进 / 跟进中 / 已完成，可下拉修改）
