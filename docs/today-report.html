莲花社区服务点 · 长者活动系统 今日更新总览

澳门街坊总会广东办事处 · 莲花社区服务点 ｜ 更新日期：2026-09-16 ｜ 版本：测试版本

一、更新概述

今日完成长者活动系统的多项功能升级，主要包括：首页门户改版、活动模块重构、考勤（请假/缺勤）功能、居民档案完善，以及新增「安心生活」专区。整体保持长者友好设计（大字、大按钮、高对比、图标配文字），数据统一存于云端，居民端与工作人员后台实时同步。

二、长者端（居民端）更新

1. 首页门户改版

  • 顶部「今日开放 / 今日休息」状态提示
  • 三大快捷入口：最新活动 / 服务项目 / 联系我们
  • 「本场活动」门户：一键进入签到 + 活动报名
  • 「今日活动提醒」：输入后四位+姓名，查询今日已报活动、提醒准时出席
  • 最新通知（支持置顶显示）、服务项目、常用办事入口
  • 保留 2-8 月活动简报，并新增 2-5 月莲花社区活动精选（含现场照片）

2. 导航与活动模块

  • 底部导航改为「首页｜活动｜服务｜我的」，新增服务项目独立页 services.html
  • 新增活动列表页 activities.html + 活动详情页；报名改为可按任意活动进行

3. 报名 / 签到流程优化

  • 报名、签到首次建档时不再采集出生年月日，统一由「我的」页首次登录时补填，减少现场录入负担

4. 考勤（请假 / 缺勤）

  • 报名后无法出席的居民可提交请假理由
  • 缺勤自动累计，连续缺勤达 5 次自动暂停报名 7 天，期满自动恢复

5. 新增「安心生活」专区

  • 三大模块：防诈骗（今日提醒+语音、6 类案例、小测试、求助）/ 脑力训练（记忆力·注意力·生活能力）/ 健康运动（4 项数据 + 记录运动）

三、工作人员后台更新

  • 新增「首页内容」管理：开放状态与联系方式、发布/置顶通知、服务项目、常用办事入口
  • 居民档案新增「出生年月日」字段；后台导出改为 Excel（照片清单内嵌缩略图）
  • 考勤管理：查看居民请假记录与缺勤状态
  • 新增「安心生活」查看页：按居民查看防诈骗阅读 / 脑力训练 / 运动记录 / 求助跟进状态，并可更新跟进进度

四、数据库新增（云端 Supabase）

今日共新增 9 张数据表，并扩展居民档案字段，全部启用行级安全（RLS）：

模块表 / 字段用途
